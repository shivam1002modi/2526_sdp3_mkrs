# Change Log

## [TIMESTAMP] Implementing Dummy Data Mode

### Files Changed
- `frontend/src/dummyData.js` (Created)
- `frontend/src/App.js` (Modified)

### Details
- Created `dummyData.js` with mock responses for chat, upload, and retrain.
- Modified `App.js` to include a `USE_DUMMY_DATA` flag.
- Intercepted `sendMessage`, `handleFileUpload`, and `handleRetrain` to use mock data when the flag is true.
- This allows the frontend to be developed and tested without the backend running.
